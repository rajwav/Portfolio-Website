## 🛠️ Systems & Projects

1. **RAJ Assistant / RAJ OS** — Local-first cognitive AI architecture with 5-tier permission rings, SQLite WAL mode, FTS5 document indexing, and multi-LLM routing.
2. **AquaNeon** — Industrial water intelligence platform with multivariate sensor anomaly detection, 24h forecasting, TreeSHAP feature attributions, and SCADA digital twin simulation.
3. **TARA** — Lightweight cognitive assistant architecture optimized for Apple Silicon with safe macOS automation and episodic memory compaction.
4. **Samvad** — High-concurrency, low-latency collaborative dialogue platform built with Next.js 16 and React 19.
5. **The Lab** — Ongoing hardware-software fusion, micro-controllers, edge telemetry, and computational physics experiments.
6. **InnoSphere** — Long-term founder initiative exploring autonomous robotics, edge intelligence, and physical-world computing.
